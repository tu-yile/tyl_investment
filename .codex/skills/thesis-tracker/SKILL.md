# 投资逻辑追踪器

description: 维护并更新投资组合持仓和观察名单标的的投资逻辑。持续跟踪关键数据点、催化剂和投资逻辑里程碑。用于根据新信息更新投资逻辑、复盘持仓理由，或检查投资逻辑是否仍然成立。触发词包括“更新 [公司] 的投资逻辑”、“我的投资逻辑还成立吗”、“投资逻辑检查”、“给 [公司] 添加数据点”或“复盘我的持仓”。

## 工作流程

### 步骤 1：定义或加载投资逻辑

如果创建新的投资逻辑：
- **公司**：名称和股票代码
- **仓位**：做多或做空
- **投资逻辑陈述**：1-2 句话说明核心投资逻辑（例如，“做多 ACME——随着业务组合转向软件，定价权 + 经营杠杆推动利润率扩张”）
- **关键支柱**：3-5 个支撑论点
- **关键风险**：3-5 个会使投资逻辑失效的风险
- **催化剂**：可能证明/证伪投资逻辑的即将发生事件（业绩、产品发布、监管决定）
- **目标价 / 估值**：如果投资逻辑兑现，它值多少钱
- **止损触发因素**：什么会让你退出

如果更新现有投资逻辑，向用户询问新的数据点或动态。

### 步骤 2：更新日志

对于每个新的数据点或动态：

- **日期**：发生时间
- **数据点**：发生了什么变化（业绩超预期、管理层离职、竞争对手动作等）
- **对投资逻辑的影响**：这是否强化、削弱某个具体支柱，或影响中性？
- **行动**：无变化 / 增加仓位 / 减仓 / 退出
- **更新后的确信度**：高 / 中 / 低

### 步骤 3：投资逻辑记分卡

维护一张持续更新的记分卡：

| 支柱 | 原始预期 | 当前状态 | 趋势 |
|--------|---------------------|----------------|-------|
| 收入增长 >20% | 按计划推进 | Q3 为 22% | 稳定 |
| 利润率扩张 | 落后 | 利润率同比持平 | 令人担忧 |
| 新产品发布 | 待定 | 推迟至 Q2 | 观察 |

### 步骤 4：催化剂日历

跟踪即将到来的催化剂：

| 日期 | 事件 | 预期影响 | 备注 |
|------|-------|-----------------|-------|
| | | | |

### 步骤 5：输出

适用于以下场景的投资逻辑总结：
- 晨会讨论
- 投资组合复盘
- 风险委员会汇报

格式：简洁的 Markdown 或 Word 文档，包含记分卡、近期更新和当前确信度水平。

## 重要说明

- 投资逻辑应当可证伪——如果没有任何事情能够推翻它，那就不是投资逻辑
- 像跟踪确认性证据一样严谨地跟踪反证证据
- 至少每季度复盘一次投资逻辑，即使没有发生重大事件
- 如果用户管理多个仓位，主动提出做完整的投资组合投资逻辑复盘
- 以结构化格式存储投资逻辑数据，以便跨会话引用
