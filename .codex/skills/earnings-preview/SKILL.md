# 业绩预览

description: 构建业绩前分析，包括预测模型、情景框架和需要关注的关键指标。用于公司发布季度业绩前准备仓位纪要、设定多头/空头情景，并识别什么会推动股价。触发词包括“业绩预览”、“[公司] 业绩需要关注什么”、“业绩前”、“业绩交易框架”或“预览 [公司] Q[X] 业绩”。

## 工作流程

### 步骤 1：收集背景

- 识别公司和报告季度
- 通过网页搜索拉取一致预期（收入、EPS、关键分部指标）
- 查找业绩日期和时间（盘前 vs. 盘后）
- 回顾公司上一季度业绩电话会中的任何指引或评论

### 步骤 2：关键指标框架

构建针对公司的“关注什么”框架：

**财务指标：**
- 收入 vs. 一致预期（总额和按分部）
- EPS vs. 一致预期
- 利润率（毛利率、经营利润率、净利率）——扩张还是收缩？
- 自由现金流
- 未来指引 vs. 一致预期

**运营指标**（行业特定）：
- 科技/SaaS：ARR、净留存、RPO、客户数
- 零售：同店销售、客流、客单价
- 工业：积压订单、订单出货比、价格 vs. 销量
- 金融：NIM、信贷质量、贷款增长、手续费收入
- 医疗健康：处方量、患者量、管线更新

### 步骤 3：情景分析

构建 3 种情景及其股价影响：

| 情景 | 收入 | EPS | 关键驱动因素 | 股价反应 |
|----------|---------|-----|------------|----------------|
| 多头 | | | | |
| 基准 | | | | |
| 空头 | | | | |

对每种情景：
- 经营层面需要发生什么
- 哪些管理层评论会释放这一信号
- 历史背景——该股票在类似业绩发布后的表现如何？

### 步骤 4：催化剂清单

识别决定股票反应的 3-5 件事：

1. [指标] vs. [一致预期/小道预期]——为什么重要
2. [指引项目]——买方希望听到什么
3. [叙事变化]——任何战略变化、并购、重组

### 步骤 5：输出

一页业绩预览，包含：
- 公司、季度、业绩日期
- 一致预期表
- 需要关注的关键指标（按重要性排序）
- 多头/基准/空头情景表
- 催化剂清单
- 交易设置：近期股价表现、期权隐含波动

## 重要说明

- 一致预期会变化——始终注明估计的来源和日期
- 来自买方调查的“小道预期”通常比公开一致预期更相关
- 历史业绩反应有助于校准预期（搜索 “[company] earnings reaction history”）
- 期权隐含波动告诉你市场预期什么——将其与你的情景进行比较
