# 最佳实践、示例和质量指南

本文档提供示例、成功技巧、应避免的常见错误，以及综合质量检查清单。

## 标题示例

### 好的业绩更新标题：
- "Nike Q2 FY24：DTC 强劲抵消批发疲弱 - 维持 OW，目标价 $95"
- "Tesla Q3'24：Cybertruck 爬坡快于计划 - 上调预测，目标价上调至 $285"
- "LVMH Q4'24：时装与皮具具韧性，葡萄酒疲弱 - 符合预期，重申买入"
- "Apple Q1 FY24：服务超预期，iPhone 低预期 - 季度表现参差，下调目标价至 $185"

### 差的标题（避免）：
- "Nike 季度更新"（过于笼统，没有要点）
- "公司发布业绩"（陈述显而易见的事实，没有分析）
- "Q3 业绩分析"（没有公司名称，没有观点）

## 成功技巧

1. **速度很重要**：业绩后 24-48 小时发布，而不是几天后

2. **先给结论**：超预期还是低预期？上调还是下调预测？

3. **量化一切**：“Strong”没有意义，“$1.2B 收入上超 $150M”很清楚

4. **聚焦驱动因素**：不要只说“收入超预期”，要解释原因

5. **展示过程**：旧预测 → 新预测，并说明原因

6. **如果重大则更新目标价**：如果预测变化 >5%，通常目标价也会变化

7. **承认电话会信息**：引用管理层评论，不要只分析新闻稿

8. **与同业比较**：如果类似公司已发布业绩，指出相对表现

9. **保持简洁**：这不是全面报告，要聚焦季度业绩

10. **绘制趋势图**：季度进展图最有价值

## 应避免的常见错误

❌ **过于全面**：不要为季度业绩写出首次覆盖长度的报告

❌ **缺少超预期/低预期**：开头说明业绩超出还是低于预期

❌ **未更新预测**：必须提供更新后的未来预测

❌ **语言含糊**：没有量化的“Strong performance”

❌ **忽视指引**：如果公司给出指引，要充分分析

❌ **太慢**：业绩后 5 天以上发布会失去相关性

❌ **重复基础信息**：不要花 3 页解释公司是做什么的

❌ **缺少目标价更新**：如果预测发生重大变化，目标价也应变化

❌ **没有投资影响**：必须将业绩与投资论点和评级联系起来

❌ **缺少引用**：每个数字都需要带可点击超链接的来源

❌ **纯文本 URL**：所有 URL 必须格式化为可点击超链接

## 综合质量控制清单

交付业绩更新前，验证以下所有事项：

### 内容与分析清单

**超预期/低预期分析：**
- [ ] 超预期/低预期分析位于报告开头
- [ ] 量化具体差异（例如，“超预期 $120M 或 3%”）
- [ ] 解释业绩为何与预期不同
- [ ] 分析每个关键指标（收入、EPS、利润率等）

**指标与表现：**
- [ ] 所有关键指标都有同比比较讨论
- [ ] 在相关情况下包含环比比较
- [ ] 提供分部/地域/产品拆分
- [ ] 分析经营指标（客户、ARPU、单位等）

**指引与预测：**
- [ ] 分析并量化指引变化（如提供）
- [ ] 如果没有指引，明确说明
- [ ] 提供当前年度更新预测
- [ ] 提供下一年度更新预测
- [ ] 清楚展示旧预测 vs. 新预测
- [ ] 解释变化内容及原因

**估值与评级：**
- [ ] 更新目标价（如果业绩支持）
- [ ] 如果目标价不变，明确维持
- [ ] 解释估值方法
- [ ] 用清晰理由确认或改变评级
- [ ] 评估投资论点并在需要时更新

### 格式与长度清单

**整体结构：**
- [ ] 报告为 8-12 页（不要更短或更长）
- [ ] 第 1 页采用业绩摘要格式
- [ ] 第 1 页标题中有 "EARNINGS UPDATE"（不是 "Initiating Coverage"）
- [ ] 事件驱动标题（例如，“Strong Q3 Results...”）

**表格：**
- [ ] 包含 1-3 张摘要表（不是全面表格）
- [ ] 所有表格都有清晰的列标题
- [ ] 所有表格都有表头行底色
- [ ] 所有表格底部都有来源行
- [ ] 预测表显示旧值 vs. 新值，并有变化列

**图表：**
- [ ] 文档中嵌入 8-12 张图表
- [ ] 所有图表上方都有 "图 X - [标题]" 标题
- [ ] 所有图表下方都有 "来源：[来源]" 行
- [ ] 图表聚焦季度趋势
- [ ] 图表突出变化（超预期/低预期、修订）
- [ ] 图表使用专业样式

### 引用与来源清单 ⭐⭐⭐ 强制

**图表与表格引用：**
- [ ] 每张图都有带文档名称和日期的具体来源
- [ ] 每张表都有具体文档引用来源
- [ ] 来源引用在适用时包含页码或幻灯片编号

**超预期/低预期引用：**
- [ ] 超预期/低预期分析引用一致预期来源（Bloomberg、FactSet 等）
- [ ] 一致预期来源包含“as of”日期（业绩发布前收盘）
- [ ] 公司报告业绩引用到业绩新闻稿或 10-Q

**指引引用：**
- [ ] 当前指引引用到业绩电话会文字记录或新闻稿
- [ ] 先前指引引用到上一季度材料
- [ ] 当前和先前指引来源都已超链接

**统计数据与指标：**
- [ ] 关键统计数据有来源脚注
- [ ] 脚注引用具体文档和页码/幻灯片编号
- [ ] 管理层引语引用发言人姓名和来源文档

**超链接：** ⭐⭐⭐ 关键
- [ ] 所有 URL 都是可点击超链接（不是纯文本）
- [ ] 超链接使用有意义的显示文本格式化
- [ ] Word 文档中使用蓝色、带下划线的超链接格式
- [ ] 超链接已测试并可用（Ctrl+Click 打开正确页面）
- [ ] 所有 SEC 文件都超链接到 EDGAR viewer
- [ ] 所有业绩材料都已超链接（新闻稿、文字记录、演示）
- [ ] 用于比较的前一季度材料已超链接
- [ ] 文档中任何地方都没有显示原始 URL

**来源部分：**
- [ ] 报告末尾包含 "来源与参考资料" 部分
- [ ] 该部分列出所有业绩材料及日期
- [ ] 所有材料都有可点击超链接
- [ ] 列出一致预期数据来源（即使订阅数据没有链接）
- [ ] 包含先前期间参考资料

### 准确性清单

**数值准确性：**
- [ ] 数字与公司报告业绩完全一致
- [ ] 所有计算中的数学结果正确
- [ ] 预测变化计算正确
- [ ] 估值数学准确
- [ ] 图表与文本描述一致

**事实准确性：**
- [ ] 股票代码无拼写错误
- [ ] 公司名称无拼写错误
- [ ] 日期是当前且准确的
- [ ] 季度/年份引用正确
- [ ] 年份标注正确（A 表示实际，E 表示预测）

### 及时性清单

**发布时间：**
- [ ] 报告在业绩发布后 24-48 小时内发布
- [ ] 如果晚于 48 小时，标注为“delayed reaction”
- [ ] ✅ **已通过搜索近期业绩验证所有数据来自最新季度**
- [ ] ✅ **没有依赖知识截止日期 - 已主动搜索当前数据**
- [ ] 一致预期是业绩前的（不是业绩后的）
- [ ] 未包含过时信息
- [ ] 业绩发布日期在最近 1-3 个月内（不是 6+ 个月前）

### 写作风格清单

**清晰与直接：**
- [ ] 用数字开头（“Revenue grew 15% to $1.2B”，而不是“Strong revenue”）
- [ ] 使用 "vs."，不要使用 "versus"
- [ ] 全文直接且简洁
- [ ] 聚焦新增信息（不要重复公司基础信息）
- [ ] 避免含糊语言（没有量化的“strong performance”）

**专业标准：**
- [ ] 保持机构语气
- [ ] 术语全文一致
- [ ] 没有非正式语言
- [ ] 正确使用财务标注

## 交付前最终检查

向用户发送报告前，完成以下快速最终检查：

### 5 分钟最终审阅：
1. **第 1 页**：评级清楚吗？目标价更新了吗？关键要点有说服力吗？
2. **数字**：报告业绩是否与公司新闻稿完全一致？
3. **引用**：抽查 3-4 张图/表 - 是否都有带可点击超链接的来源？
4. **预测**：旧值 vs. 新值是否清楚展示？变化是否解释？
5. **图表**：是否全部嵌入 8-12 张？是否全部编号并加标题？
6. **长度**：是否为 8-12 页（不是 6 页，也不是 15 页）？
7. **超链接**：测试 3-4 个超链接 - 是否能通过 Ctrl+Click 打开？
8. **及时性**：这是否在业绩后 48 小时内发布？

如果所有事项都通过，报告即可交付。

## 摘要交付格式

向用户交付完成的报告时，提供以下摘要：

```
[Company] Q[X] [Year] 业绩更新完成

业绩结果：[超预期 / 符合预期 / 低预期]
- 收入：$X.XB（[超出/低于] $XXM 或 X%）
- EPS：$X.XX（[超出/低于] $X.XX）

关键要点：
■ [要点 1]
■ [要点 2]
■ [要点 3]

更新后的预测：
- FY[Year]E 收入：$XX.XB（先前：$XX.XB，[+/-]X%）
- FY[Year]E EPS：$X.XX（先前：$X.XX，[+/-]X%）

评级：[维持 / 上调 / 下调] [RATING]
目标价：$XXX（先前：$XXX）- [+/-]XX% 上行空间

交付物：
✓ 8-12 页业绩更新报告（DOCX）
✓ 8-12 张嵌入式图表
✓ 带旧/新比较的更新预测
✓ 带可点击超链接的完整来源部分
✓ [可选：更新后的 XLS 财务模型]

File: [Company]_Q[X]_[Year]_Earnings_Update.docx
```
