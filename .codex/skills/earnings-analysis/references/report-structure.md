# 报告结构和模板

本文档提供业绩更新 DOCX 报告的完整逐页模板和格式要求。

## 完整报告结构

## 第 1 页：业绩摘要

**顶部部分 - 标题：**
```
[COMPANY NAME] ([TICKER])
[QUARTER] [YEAR] EARNINGS UPDATE

[当前日期]

评级：[维持/上调/下调] [RATING]
价格（截至 [date]）：$XX.XX
目标价：[如有变化则 OLD → NEW，或维持 $XXX]
```

**顶部部分 - 快速摘要框：**
```
业绩摘要
─────────────────────────────────────────────────
Q[X] [YEAR] 业绩结果：[超预期 / 符合预期 / 低预期]

                报告值      预测     差异
收入            $X,XXX      $X,XXX   +$XXX (+X%)
EPS（调整后）   $X.XX       $X.XX    +$X.XX (+X%)

关键要点：
■ [要点 1 - 一句话]
■ [要点 2 - 一句话]
■ [要点 3 - 一句话]
```

**主体内容 - 投资影响（3-4 条 bullet）：**

使用 ■ 字符，并配合**加粗标题**和段落长度说明：

```
■ **业绩因强劲的 [segment/geography/product] 超预期，维持积极动能**

Q[X] 收入 $X.XB，比我们 $X.XB 的预测高 X%，比一致预期高 X%，
主要由 [specific driver] 推动。[Segment] 收入同比增长 X%（vs. 我们
X% 的预测），而 [segment] 增长 X%（vs. X% 预测）。管理层强调
[specific products/initiatives] 是关键增长驱动因素，并对前景保持自信
语气。该超预期体现了 [thesis point]，强化了我们的正面
观点。

■ **尽管存在 [headwind]，利润率同比扩大 XXbps，体现经营杠杆**

[详细利润率分析段落...]

■ **指引上调 / 维持 / 下调 - 意味着 [interpretation]**

[详细指引分析段落...]

■ **维持 [RATING]，目标价 [上调/不变] 至 $XXX**

[投资结论段落...]
```

EBITDA ($M)          X,XXX          X,XXX          +X%     X,XXX

## 格式要求

### 1. 第 1 页要求
- 清晰评级（MAINTAIN OUTPERFORM、RAISE TO BUY 等）
- 突出显示更新后的目标价
- 包含旧/新预测的摘要表
- 3-4 条使用 ■ 字符的段落长度 bullet

### 2. 所有表格要求
- 底部有来源行
- 清晰的列标题
- 表头行有底色

### 3. 所有图表要求
- 上方有 "图 X - [标题]" 标题
- 下方有 "来源：[来源]" 行
- 专业样式

### 4. 年份标注
- 用 A 表示实际（Q3'24A）
- 用 E 表示预测（Q4'24E）

### 5. 写作风格
- 用数字开头（“Revenue grew 15% to $1.2B”，而不是“Strong revenue growth”）
- 使用 "vs."，不要使用 "versus"
- 直接且简洁
- 聚焦新增信息

### 6. 超链接要求 ⭐⭐⭐
- 所有 URL 必须是 Word 中可点击超链接
- 蓝色、带下划线文本，可通过 Ctrl+Click 打开
- 显示文本有意义（不是原始 URL）
- 每个来源引用在适用时都应有可点击链接
- 不使用纯文本 URL - 始终格式化为超链接
