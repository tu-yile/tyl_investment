# 业绩更新的详细工作流程

本文档为业绩更新流程的每个阶段提供详细的逐步说明。

## ⚠️⚠️⚠️ 关键警告：始终使用最新业绩数据 ⚠️⚠️⚠️

**先停下并阅读这里：**

训练数据已经过时。主动搜索并获取最新的业绩材料。使用过时业绩数据是业绩分析中的第一大错误。

**开始前：**
1. **检查今天的日期** - 写下当前日期
2. **搜索最新信息** - 使用网络搜索查找最近一期业绩
3. **验证日期** - 确认业绩新闻稿在最近 3 个月内
4. **如果早于 3 个月** - 获取了错误季度，重新搜索

## 阶段 1：业绩数据收集（30-60 分钟）

### 步骤 1：识别最新业绩期间

**关键**：始终搜索最新业绩 - 不要依赖知识截止日期。
**关键**：绝不要使用训练中的业绩数据 - 它已经过时。

**步骤 1a：搜索最新业绩新闻稿**

**🚨 主动搜索 - 训练数据已经过时。🚨**

**强制步骤 1：检查今天的日期**
- **明确写下今天的日期**：[Month] [Day], [Year]
- **用这个日期验证**找到的任何业绩都在 3 个月内
- **示例**："Today is October 29, 2024"

**强制步骤 2：搜索 "LATEST EARNINGS"**
- **使用网络搜索**，查询例如：
  - `[Company name] latest earnings results`
  - `[Company name] most recent quarterly earnings`
  - `[Ticker symbol] earnings latest quarter`
- **或者搜索公司投资者关系网站**：
  - 访问 `investor.[company].com` 或 `[company].com/investors`
  - 导航到 "Press Releases"、"News" 或 "Earnings" 部分
  - **按日期排序以找到最新新闻稿**
  - 查找关键词："earnings"、"results"、"financial results"、"quarterly results"

**强制步骤 3：验证发布日期**
- **查看找到的业绩新闻稿日期**
- **计算**：该日期是否在今天之前最近 3 个月内？
- **如果是** → 继续下一步
- **如果不是（早于 3 个月）** → 🚨 错误季度 - 重新搜索更近期内容

**❌ 应避免的常见错误：**
- ❌ 不搜索就使用训练数据中的业绩数据
- ❌ 基于预期假设 "Q3 2024" 是最新季度
- ❌ 抓取第一个找到的业绩新闻稿而不检查日期
- ❌ 不将发布日期与今天的日期比较
- ❌ 当新闻稿已超过 4 个月仍继续

**✅ 正确做法：**
- ✅ 先检查今天的日期
- ✅ 明确搜索 "latest" 或 "most recent"
- ✅ 阅读材料上的实际发布日期
- ✅ 确认发布日期在今天之前 3 个月内
- ✅ 如果不确定，用不同关键词再次搜索

**强制步骤 4：识别季度**
- **阅读标题/标题行**以识别季度（Q1、Q2、Q3、Q4 或财年季度）
- **阅读文档本身的发布日期**
- **验证季度名称和日期都很近期**

3. **如果 IR 网站不清楚，使用替代搜索方法：**
   - 网络搜索：`[Company name] latest earnings results`
   - 网络搜索：`[Company name] most recent quarterly earnings`
   - 网络搜索：`[Ticker symbol] earnings latest quarter`
   - SEC EDGAR：搜索公司并查看最近的 10-Q 或 10-K 提交日期

**可找到最新数据的示例搜索：**
- "Nike latest earnings results" → 返回最近报告的季度
- "AAPL most recent quarterly earnings" → 显示 Apple 最新业绩
- "Tesla Q3 2024 earnings" → 结果确认 Q3 2024 存在

**步骤 1b：理解公司的财年日历**

通过搜索识别最新季度后，理解公司的财年以正确解读：

**常见财年模式：**
- **日历年（CY）**：Q1=1-3 月，Q2=4-6 月，Q3=7-9 月，Q4=10-12 月
- **Nike 财年**：Q1=6-8 月，Q2=9-11 月，Q3=12-2 月，Q4=3-5 月（5 月财年结束）
- **Apple 财年**：Q1=10-12 月，Q2=1-3 月，Q3=4-6 月，Q4=7-9 月（9 月财年结束）
- **Walmart 财年**：Q1=2-4 月，Q2=5-7 月，Q3=8-10 月，Q4=11-1 月（1 月财年结束）

许多公司会在业绩新闻稿标题中说明财年。如有需要，搜索 `[company] fiscal year calendar`。

**步骤 1c：强制验证 - 验证已获得最新数据**

🛑 **停止 - 在验证以下全部事项前不要继续：**

- [ ] ✅ **已写下今天的日期**：[Month] [Day], [Year]
- [ ] ✅ **已主动搜索**，使用 "latest earnings" 或 "most recent earnings"
- [ ] ✅ **已找到业绩发布日期**：[Month] [Day], [Year]
- [ ] ✅ **已验证新闻稿在今天之前 3 个月内**（做数学计算！）
- [ ] ✅ **没有仅根据今天日期假设**季度
- [ ] ✅ **可以看到实际新闻稿**确认季度/期间
- [ ] ✅ **已打开并阅读**实际业绩材料（不是仅假设它们存在）

**🚨 红旗 - 如果任何一项为真，则获取了错误季度：**
- 🚨 发布日期超过 90 天
- 🚨 依赖预期，而不是通过搜索找到的内容
- 🚨 尚未实际看到确认该季度存在的新闻稿或文件
- 🚨 未搜索就使用训练数据
- 🚨 无法说明确切发布日期
- 🚨 在今天是 2024+ 年时，找到的发布日期来自 2023 年或更早

**如果存在任何红旗**：停止并重新搜索。不要继续使用过时数据。

**步骤 1c：处理命名差异**

公司使用不同术语 - 识别以下模式：

**季度术语：**
- "Q1 2024", "Q1 FY24", "First Quarter 2024", "1Q24"
- "Third Quarter Fiscal 2024", "Q3 FY2024", "3Q FY24"

**业绩新闻稿标题：**
- "[Company] Reports Q3 2024 Results"
- "[Company] Announces Third Quarter Fiscal 2024 Financial Results"
- "[Company] Q3 Revenue Grew 15% Year-over-Year"

**SEC 文件搜索：**
- 公司名称可能不同于常用名称（例如，"Meta Platforms, Inc." vs "Facebook"）
- 用股票代码搜索以可靠地找到文件
- 查找最近的 10-Q（季度）或 10-K（如果是 Q4 则为年度）

### 步骤 2：收集业绩材料

在搜索并确认最新季度后，收集以下内容：

**⚠️ 重要：搜索并访问实际文档 - 不要依赖训练数据。**

**主要材料（必需）：**
- **业绩新闻稿** - 通常在公司投资者关系网站的 "Press Releases" 或 "News" 下
  - 导航到 IR 网站并找到实际新闻稿
  - 搜索模式："[Company name] latest earnings", "[Company name] Q[X] [Year] earnings results"
  - 查找 PDF 或 HTML 版本
  - **验证日期与步骤 1 中找到的日期一致**（应在最近 1-3 个月内）
  - **阅读实际文档**以确认季度并获取报告数字

- **10-Q 或 10-K 文件** - 在 SEC EDGAR（sec.gov/edgar/searchedgar/companysearch.html）
  - 用股票代码搜索
  - 对第 1-3 季度：查找最近的 10-Q
  - 对 Q4：查找 10-K（年度报告）
  - 注：可能在业绩发布后 1-5 天提交
  - 直接链接格式：`https://www.sec.gov/cgi-bin/viewer?accession=[accession-number]`

- **业绩电话会文字记录** - 🚨 **验证文字记录上的日期** 🚨
  - **搜索**："[Company] latest earnings call transcript" 或 "[Company] Q[X] [Year] earnings call transcript"
  - **来源**：
    - 公司 IR 网站（有些会直接发布文字记录）
    - Seeking Alpha：搜索 "[Company] [latest quarter] earnings call transcript"
    - AlphaStreet、Motley Fool（替代来源）
  - **关键日期检查**：
    - ✅ **使用任何文字记录前，验证文字记录本身的日期**
    - ✅ **文字记录日期必须与步骤 1 的业绩发布日期一致**
    - ✅ **如果文字记录显示 "Q2 2023" 但新闻稿是 "Q3 2024"，则获取了错误文字记录**
    - 🚨 **常见错误**：不检查日期就抓取旧文字记录
  - 如果文字记录尚不可用，收听网络回放或注明等待文字记录

**补充材料（如有）：**
- **投资者演示/幻灯片** - 通常与新闻稿一起发布在 IR 网站
  - 通常标题为 "Q[X] [Year] Earnings Presentation" 或 "Investor Presentation"
  - PDF 格式，包含管理层在业绩电话会上展示的幻灯片

- **补充数据文件** - 有些公司提供包含详细指标的 Excel 文件
  - 查找 "Supplemental Financial Information" 或 "Investor Data Sheet"

**参考材料（用于比较）：**
- **上一季度业绩** - 用于环比比较
  - 来自上一季度业绩新闻稿（90 天前）

- **去年同期季度** - 用于同比比较
  - 来自去年同一季度（4 个季度前）

- **先前预测** - 如果该公司此前已被覆盖
  - 来自上一份业绩更新或首次覆盖报告
  - 检查此前对本季度指标的预测

- **一致预期** - 来自 Bloomberg、FactSet、Refinitiv 或 Yahoo Finance
  - 关键：使用业绩发布前的预测
  - 查找 "as of [date before earnings]" 以确保是发布前一致预期
  - 超预期/低预期分析所需

**🛑 进入步骤 3 前的强制验证：**

**日期 - 验证所有日期匹配：**
- [ ] ✅ **已写下今天的日期**：_______________
- [ ] ✅ **业绩发布日期**：_______________（必须在今天之前 3 个月内）
- [ ] ✅ **业绩电话会文字记录日期**：_______________（必须与发布日期 ±1 天一致）
- [ ] ✅ **10-Q/10-K 提交日期**：_______________（必须与新闻稿同一季度）
- [ ] ✅ **所有材料显示同一季度**（例如都写 "Q3 2024"，不是混合季度）

**搜索与访问 - 验证已完成主动搜索：**
- [ ] ✅ **已搜索** "latest earnings"（不是基于当前日期假设）
- [ ] ✅ **已访问**实际业绩新闻稿并阅读
- [ ] ✅ **已打开**实际业绩电话会文字记录并验证日期
- [ ] ✅ **已确认**通过检查日期确定这是最新季度
- [ ] ✅ 有来自实际新闻稿的完整财务业绩（收入、EPS、利润率等）
- [ ] ✅ 有带来源日期的业绩前一致预期

**🚨 红旗 - 如果任何一项为真则停止：**
- 🚨 没有实际搜索或访问业绩材料
- 🚨 基于记忆或训练数据，而不是当前文档
- 🚨 业绩发布日期超过 90 天
- 🚨 无法说明业绩发布的确切日期
- 🚨 文字记录日期与发布日期不匹配
- 🚨 材料显示不同季度（例如新闻稿写 Q3，但文字记录写 Q2）
- 🚨 抓取第一个结果而未验证日期

### 步骤 4：识别电话会中的关键主题

收听或阅读业绩电话会文字记录，并记录：
- 管理层语气（自信、谨慎、防御性？）
- 强调的关键主题（产品发布、地域趋势、竞争）
- 分析师提问（投资者关心什么？）
- 给出的指引（上调、下调、维持、首次给出？）
- 任何意外或出人意料的评论

## 阶段 2：分析（2-3 小时）

### 步骤 5：超预期/低预期分析

对每个超出或低于预期的关键指标，解释：

**如果超预期：**
- 是什么推动了超预期表现？
- 这是一次性的还是可持续的？
- 管理层是否上调未来指引？
- 这如何影响我们的投资论点？

**如果低预期：**
- 哪里出了问题？
- 是公司特定问题还是行业范围问题？
- 管理层是否采取纠正行动？
- 这如何影响我们的投资论点？

**示例格式：**
```
■ **收入因强劲 DTC 表现超预期 3%**

$13.5B 收入比我们 $13.1B 的预测高 $400M（3%），比一致预期
$13.2B 高 $300M（2%）。超预期主要由 Direct-to-
Consumer 渠道推动，该渠道同比增长 18%（vs. 我们 12% 的预测），抵消了
低于预期的 wholesale（-5% vs. 持平预测）。管理层指出强劲的
数字需求和成功的产品发布（Pegasus 40 跑鞋、新
Jordan 配色）是关键驱动因素。DTC 目前占总收入的 42%，而
一年前为 38%，显示渠道转型战略成功。
```

### 步骤 6：分部/地域/产品分析

按以下维度分析表现：
- 业务分部（如果是多分部公司）
- 地域（北美、欧洲、中国等）
- 产品类别
- 渠道（零售、批发、电商）

识别：
- 什么超出预期？
- 什么低于预期？
- 相比前几个季度的趋势
- 管理层对各领域前景的评论

### 步骤 7：利润率分析

分析盈利能力：
- 毛利率：上升还是下降？为什么？
- 经营利润率：上升还是下降？为什么？
- 关键驱动因素（定价、组合、成本、杠杆）
- 未来展望

### 步骤 8：指引分析

如果公司给出指引：
- 将新指引与先前指引比较
- 与内部预测和市场预测比较
- 评估可信度（公司是否有保守指引？经常超预期？）
- 识别指引背后的关键假设

如果公司未给出指引：
- 明确说明这一点
- 基于业绩和评论提供独立展望

### 步骤 9：更新财务模型

更新以下预测：
- 当前年度（剩余季度）
- 下一年度
- 可能还包括再下一年

**清楚展示：**
```
更新后的预测：
─────────────────────────────────────────────────
                        旧预测      新预测      变化        原因
FY2024E 收入            $XX.XB      $XX.XB      +X.X%      [简要原因]
FY2024E EBITDA          $X.XB       $X.XB       +X.X%      [简要原因]
FY2024E EPS             $X.XX       $X.XX       +X.X%      [简要原因]

FY2025E 收入            $XX.XB      $XX.XB      +X.X%      [简要原因]
FY2025E EBITDA          $X.XB       $X.XB       +X.X%      [简要原因]
FY2025E EPS             $X.XX       $X.XX       +X.X%      [简要原因]
```

### 步骤 10：更新估值与目标价

基于更新后的预测：
- 重新计算 DCF（使用更新后的现金流）
- 更新可比公司倍数（如果同业已发布业绩）
- 确定新的公允价值
- 决定目标价是否变化

**目标价决策：**
- 如果预测显著变化（>5%）→ 通常改变目标价
- 如果预测小幅变化（<5%）→ 可以维持目标价
- 如果投资论点增强/减弱 → 即使预测不变也可能改变

### 步骤 11：评估评级影响

决定是否改变评级：
- 如果业绩显著好于预期 + 上调指引 → 考虑上调评级
- 如果业绩显著差于预期 + 下调指引 → 考虑下调评级
- 如果符合预期或好坏参半 → 通常维持评级

**考虑：**
- 股价反应（上涨/下跌/持平？）
- 估值（相对新预测是贵还是便宜？）
- 风险/回报（不对称性是否变化？）

## 阶段 3：图表生成（1-2 小时）

### 步骤 12：生成 8-12 张图表

创建聚焦季度趋势和新增信息的图表。

**必需图表（共 8-12 张）：**

1. **季度收入进展**（柱状图）
   - 最近 8-12 个季度
   - 显示每个季度相对预测的超预期/低预期
   - 突出当前季度

2. **季度 EPS 进展**（柱状图）
   - 最近 8-12 个季度
   - 显示相对预测的超预期/低预期
   - 调整后和 GAAP

3. **季度利润率趋势**（折线图）
   - 毛利率、EBIT 利润率、净利率
   - 最近 8-12 个季度
   - 显示轨迹

4. **按分部/地域划分的收入**（堆叠柱状图或表格）
   - 当前季度 vs. 同比
   - 各分部增长率

5. **关键经营指标**（多折线图）
   - 客户数、ARPU、销量等（任何相关指标）
   - 最近 8-12 个季度

6. **超预期/低预期摘要**（瀑布图或表格）
   - 显示超预期/低预期的组成部分
   - 什么驱动了相对预测的差异

7. **预测修订图**（前后对比）
   - 旧 FY 预测 vs. 新 FY 预测
   - 显示变化的柱状图

8. **估值图表**（P/E 或 EV/EBITDA 倍数）
   - 历史倍数区间
   - 当前倍数
   - 公允价值倍数

**可选图表（如空间允许）：**
- 同业比较（如果同业已发布业绩）
- 指引 vs. 市场预期比较
- 现金流指标
- 资产负债表亮点（如值得注意）

**图表样式指南：**
- 聚焦趋势（季度进展）
- 突出变化（超预期/低预期、预测修订）
- 保持简单清晰（这是快速周转报告）

## 阶段 4：报告创建（2-3 小时）

### 步骤 13：创建 DOCX 报告

使用 DOCX skill 创建 8-12 页报告。

请参阅 [report-structure.md](report-structure.md)，了解完整逐页模板和格式要求。

**关键步骤：**
1. 创建带业绩摘要和快速要点的第 1 页
