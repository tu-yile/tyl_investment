# 模型更新

description: 用新数据更新财务模型——季度业绩、管理层指引、宏观变化或修订后的假设。调整预测、重新计算估值，并标记重大变化。用于业绩发布后、指引更新后，或假设需要刷新时。触发词包括“更新模型”、“填入业绩数据”、“刷新预测”、“更新 [公司] 的数据”、“新指引”或“修订预测”。

## 工作流程

### 步骤 1：识别发生了什么变化

确定更新触发因素：
- **业绩发布**：需要填入新的季度实际数据
- **指引变化**：公司更新了前瞻展望
- **预测修订**：分析师基于新数据改变假设
- **宏观更新**：利率、汇率、大宗商品价格变化
- **事件驱动**：并购、重组、新产品、管理层变动

### 步骤 2：填入新数据

#### 业绩发布后
用已报告的实际数据更新模型：

| 项目 | 先前估计 | 实际 | 差异 | 备注 |
|-----------|---------------|--------|-------|-------|
| 收入 | | | | |
| 毛利率 | | | | |
| 经营费用 | | | | |
| EBITDA | | | | |
| EPS | | | | |
| [关键指标 1] | | | | |
| [关键指标 2] | | | | |

**分部明细**（如适用）：
- 更新每个分部的收入和利润率
- 标注任何分部组合变化

**资产负债表 / 现金流更新**：
- 现金和债务余额
- 股本数量（回购、稀释）
- Capex 实际 vs. 估计
- 营运资本变化

### 步骤 3：修订前瞻预测

基于新数据，调整前瞻预测：

| | 旧 FY 估计 | 新 FY 估计 | 变化 | 旧下一 FY | 新下一 FY | 变化 |
|---|-----------|-----------|--------|------------|------------|--------|
| 收入 | | | | | | |
| EBITDA | | | | | | |
| EPS | | | | | | |

**关键假设变化：**
- 你在改变哪些假设，为什么？
- 收入增长率：旧 → 新（原因）
- 利润率假设：旧 → 新（原因）
- 任何新增项目（重组费用、一次性收益等）

### 步骤 4：估值影响

用更新后的预测重新计算估值：

| 估值方法 | 先前 | 更新后 | 变化 |
|-----------------|-------|---------|--------|
| DCF 公允价值 | | | |
| P/E（NTM EPS × 目标倍数） | | | |
| EV/EBITDA（NTM EBITDA × 目标倍数） | | | |
| **目标价** | | | |

### 步骤 5：总结与行动

**预测变化总结：**
- 一段话：发生了什么变化、为什么变化，以及这对股票意味着什么
- 这是会改变投资逻辑的事件，还是噪音？

**评级 / 目标价：**
- 维持或改变评级？
- 新目标价（如有变化）及方法论
- 相对当前价格的上行/下行空间

### 步骤 6：输出

- 更新后的 Excel 模型（如果用户提供现有模型）
- 预测变化总结（Markdown 或 Word）
- 更新后的目标价推导

## 重要说明

- 在向前预测前，始终将你的估计与公司报告数据核对一致
- 标注任何非经常性项目，以及你的估计是 GAAP 还是调整后口径
- 跟踪你的预测修订历史——它展示你的分析进程
- 如果该季度噪音较多，在预测变化中区分信号与噪音
- 更新后检查一致预期——你修订后的预测与华尔街相比如何？
- 股本数量很重要——股权激励、可转债或回购带来的稀释可能对 EPS 产生重大影响
