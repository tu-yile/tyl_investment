# 行业概览

description: 创建全面的行业和板块格局报告，覆盖市场动态、竞争定位、关键参与者和主题趋势。用于客户需求、行业首次覆盖、主题研究报告或内部知识建设。触发词包括“行业概览”、“行业报告”、“市场格局”、“行业分析”、“行业深度研究”或“主题研究”。

## 工作流程

### 步骤 1：定义范围

- **行业 / 子行业**：是什么行业，定义到多窄？
- **目的**：客户报告、内部研究、推介材料、想法生成
- **深度**：高层概览（5-10 页）或深度研究（20-30 页）
- **角度**：中性格局 vs. 主题投资逻辑（例如，“AI 基础设施建设”）
- **研究范围**：仅上市公司，还是包括非上市公司？

### 步骤 2：市场概览

**市场规模与增长**
- 总可寻址市场（TAM）及来源
- 历史增长率（5 年 CAGR）
- 预测增长率和关键假设
- 市场细分（按产品、地域、终端市场、客户类型）

**行业结构**
- 分散 vs. 集中——前 5 名市场份额
- 价值链地图——价值在哪里沉淀？
- 商业模式类型（订阅、交易、授权、服务）
- 进入壁垒（资本、监管、技术、网络效应）

**关键趋势与驱动因素**
- 长期顺风（3-5 个主要趋势）
- 逆风和风险
- 技术颠覆路径
- 监管发展
- 并购活动和整合趋势

### 步骤 3：竞争格局

**公司画像**（针对前 5-10 个参与者）：

| 公司 | 收入 | 增长 | EBITDA 利润率 | 市场份额 | 关键差异化因素 |
|---------|---------|--------|--------------|-------------|-------------------|
| | | | | | |

对每家公司，提供简要画像：
- 业务描述（2-3 句话）
- 战略定位和护城河
- 近期动态（业绩、并购、产品发布）
- 估值快照（P/E、EV/EBITDA、EV/Revenue）

**竞争动态**
- 公司如何竞争？（价格、产品、服务、渠道）
- 谁在获得/失去份额，为什么？
- 来自新进入者或相邻玩家的颠覆风险

### 步骤 4：估值背景

- 行业交易倍数（当前和历史区间）
- 溢价/折价驱动因素（增长、利润率、市场地位）
- 近期并购交易倍数
- 该行业与更广泛市场相比如何？

### 步骤 5：投资启示

- 最好的风险/回报机会在哪里？
- 可以通过该行业表达哪些主题下注？
- 行业中的关键争论（多头 vs. 空头论点）
- 可能改变行业叙事的催化剂

### 步骤 6：输出

- Word 文档或 PowerPoint，包含：
  - 市场概览和规模测算
  - 竞争格局地图
  - 公司比较表
  - 估值总结
  - 关键图表：市场增长、份额趋势、估值历史
- 含详细公司数据的 Excel 附录

## 重要说明

- 为所有市场规模数据标注来源——引用研究机构或方法论
- 区分 TAM 炒作和现实可寻址市场
- 行业概览老化很快——注明日期，并标记可能过时的数据
- 图表必不可少——市场规模瀑布图、竞争定位矩阵、估值散点图
- 如果面向客户，需根据其具体情况调整“所以怎样”（并购标的识别、竞争定位、市场进入）
