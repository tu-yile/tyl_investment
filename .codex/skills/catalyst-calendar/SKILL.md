# 催化剂日历

description: 构建并维护覆盖范围内即将到来的催化剂日历——业绩日期、会议、产品发布、监管决定和宏观事件。帮助确定关注重点，并在事件前进行仓位安排。触发词包括“催化剂日历”、“即将发生的事件”、“接下来有什么事件”、“业绩日历”、“事件日历”或“催化剂追踪器”。

## 工作流程

### 步骤 1：定义覆盖范围

- 要跟踪的公司列表（股票代码或名称）
- 板块 / 行业重点
- 是否包含宏观事件？（美联储会议、经济数据、监管截止日期）
- 时间范围（未来 2 周、1 个月、1 个季度）

### 步骤 2：收集催化剂

对每家公司，识别即将发生的事件：

**业绩与财务事件**
- 季度业绩日期和时间（盘前/盘后）
- 年度股东大会
- 投资者日 / 分析师日
- 资本市场日
- 债务到期 / 再融资日期

**公司事件**
- 产品发布或公告
- FDA 批准 / 监管决定
- 合同续签或到期
- 并购里程碑（交割日期、监管批准）
- 管理层交接
- 内部人交易窗口（锁定期到期）

**行业事件**
- 主要会议（日期、哪些公司参会演讲）
- 贸易展和博览会
- 监管意见征询期或裁决
- 行业数据发布（月度销售、客流等）

**宏观事件**
- 美联储会议（FOMC 日期）
- 就业报告、CPI、GDP 发布
- 中央银行决策（ECB、BOJ 等）
- 对市场有影响的地缘政治事件

### 步骤 3：日历视图

| 日期 | 事件 | 公司/行业 | 类型 | 影响（高/中/低） | 我们的仓位安排 | 备注 |
|------|-------|---------------|------|-----------------|----------------|-------|
| | | | 业绩/公司/行业/宏观 | | 做多/做空/中性 | |

### 步骤 4：每周预览

每周生成一份前瞻性总结：

**本周关键事件：**
1. [星期]：[公司] Q[X] 业绩——一致预期 [$X EPS]，我们的估计 [$X]，关键关注：[指标]
2. [星期]：[事件]——为什么它对 [股票] 重要
3. [星期]：[宏观发布]——预期和仓位安排

**下周预览：**
- 提前提示即将到来的重要事件

**仓位启示：**
- 可能影响具体仓位的事件
- 是否建议提前布局
- 二元事件前的风险管理

### 步骤 5：输出

- 含日历视图和可排序列的 Excel 工作簿
- 每周预览邮件/纪要（Markdown）
- 可选：与 Google Calendar 集成

## 重要说明

- 业绩日期会变化——临近日期时需根据公司 IR 页面和 Bloomberg/FactSet 验证
- 预告风险：跟踪有业绩预告历史的公司（正面或负面）
- 会议出席名单很有价值——哪些公司参会演讲，哪些公司明显缺席？
- 有些催化剂是周期性的（月度行业数据）——建立模板并自动填充
- 按影响等级进行颜色编码：红色 = 高影响，黄色 = 中等，绿色 = 常规
- 归档过去催化剂及其实际结果——随着时间推移建立模式识别
