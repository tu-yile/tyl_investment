# 晨会纪要

description: 起草简洁的晨会纪要，总结隔夜动态、交易想法和覆盖股票的关键事件。为早上 7 点晨会格式设计——紧凑、有观点、可行动。触发词包括“晨会纪要”、“晨会”、“隔夜发生了什么”、“交易想法”、“晨会准备”或“每日纪要”。

## 工作流程

### 步骤 1：隔夜动态

扫描覆盖范围内的相关事件：

**业绩与指引**
- 是否有任何覆盖公司在隔夜或盘前发布业绩？
- 业绩意外（收入、EPS、关键指标超预期/低于预期）
- 指引变化（上调、下调、维持）

**新闻与事件**
- 并购公告或传闻
- 管理层变动
- 产品发布或监管决定
- 竞争对手分析师上调/下调评级
- 影响该行业的宏观数据或政策变化

**市场背景**
- 隔夜期货 / 盘前走势
- 行业 ETF 表现
- 相关大宗商品或汇率变动
- 今日关键经济数据发布

### 步骤 2：晨会纪要格式

保持紧凑——晨会纪要应能在 2 分钟内读完：

---

**[日期] 晨会纪要——[分析师姓名]**
**[覆盖行业]**

**首要观点：[标题——PM 需要听到的最重要事项]**
- 用 2-3 句话说明关键动态及其重要性
- 对股票的影响：目标价、评级维持/变更

**隔夜/盘前动态**
- [公司 A]：用一行总结业绩/新闻 + 我们的看法
- [公司 B]：一行总结 + 我们的看法
- [行业/宏观]：相关的全行业动态

**今日关键事件**
- [时间]：[公司] 业绩电话会
- [时间]：经济数据发布（预期 vs. 我们的观点）
- [时间]：会议或投资者日

**交易想法**（如有）
- [做多/做空] [公司]：1-2 句话说明投资逻辑 + 催化剂
- 风险：什么会使这个判断错误

---

### 步骤 3：业绩速评

如果覆盖公司已发布业绩，提供快速反应：

| 指标 | 一致预期 | 实际 | 超预期/低于预期 |
|--------|-----------|--------|-----------|
| 收入 | | | |
| EPS | | | |
| [关键指标] | | | |
| 指引 | | | |

**我们的看法**：2-3 句话——这对股票是好是坏？是否改变我们的投资逻辑？

**行动**：维持 / 上调 / 下调评级？调整目标价？

### 步骤 4：输出

- 用于邮件/Slack 分发的 Markdown 文本
- 最多保持在 1 页内——PM 和交易员不会读更多

## 重要说明

- 要有观点——只总结新闻而没有观点的晨会纪要没有用
- 从最重要的事开始——不要把标题埋起来
- “没有新闻”也是有效的晨会纪要——说明“隔夜无重大事项，维持仓位”
- 区分可行动事件（业绩、并购）和噪音（小型分析师报告、非事件）
- 给你的观点标注时间——如果你在早上 6 点写，注明盘前情况可能会在开盘前变化
- 如果你错了，在下一份晨会纪要中承认——可信度比每次都正确更重要
