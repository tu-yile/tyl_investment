# 股票研究首次覆盖报告模板

本模板提供了创建全面股票研究首次覆盖报告的结构。在构建最终报告文档时，请将其作为指南使用。

**注意：** 实际报告必须使用 DOCX 技能创建。不要生成 Markdown 内容。

**关键要求：**
1. 在创建 Word 文档之前，使用 Python (matplotlib/plotly) **生成 20-30+ 张图表图片**
2. **使用 DOCX 技能**：创建具有适当样式、页眉/页脚和格式的专业报告
3. **嵌入实际图表图片**：在 Word 文档的适当位置插入生成的 PNG/JPG 图表文件
4. **不要使用 MARKDOWN**：不要生成 Markdown 内容。使用 DOCX 技能创建 .docx 文件。

**关键格式指导：**
- **最大密度**：每一页都应充满信息。在全文中交错安排文本、图表和表格。
- **无孤立章节**：绝不要让章节标题单独出现，也不要让单张图表独占一页。
- **20-30+ 张实际图表图片**：将图表生成为图片文件，然后使用 DOCX 技能嵌入文本章节中。

## 第 1 页：投资更新（最重要页面）

**关键**：第 1 页不是传统的执行摘要。它是**投资更新**，采用专业股票研究机构使用的特定机构格式。

**重要结构说明：**
- 这是“投资更新”或“公司更新”页面，不是“执行摘要”
- 左上角使用评级框
- 突出显示股价表现图（图 1）
- 包含 3-4 条带 ■ 字符的详细要点
- 每条要点都有**加粗主题标题**，后接 3-5 句说明
- 底部部分有财务和估值指标表
- 所有图表都必须有图号（图 1、图 2 等）和来源行

## 图表编号和格式标准

**关键**：所有图表、图形和表格都必须遵循专业股票研究中使用的严格图表编号惯例。

### 图表编号格式

**每张图表/表格必须包含：**
1. **连续编号**：图 1、图 2、图 3 等。（在整份报告中持续连续编号）
2. **描述性标题**：“图 X - [公司] [具体指标] [图表/分析类型]”
3. **来源行**（始终在底部）：“来源：公司数据，[机构名称] 估计。”

**示例：**
- 图 1 - [公司] 股价表现
- 图 2 - [公司] 按产品划分的历史和预测收入组合
- 图 3 - [公司] 按地理区域划分的收入
- 图 4 - [产品名称] 每名患者每年收入和价格
- 图 5 - [公司] 毛利率演变
- 图 6 - DCF 敏感性分析（$/股）
- 图 7 - 估值足球场图

### 图注格式

```
图 X - [描述性标题]
[图表/表格/图形内容]
来源：公司数据，[机构名称] 估计。
```

对于具有多个数据来源的表格：
```
图 X - [描述性标题]
[表格内容]
来源：公司申报文件，FactSet，[机构名称] 估计。
```

### 放置指南

- 图表应按在报告中出现的顺序编号
- 第一张图（图 1）通常是第 1 页上的股价图或收入增长轨迹
- 每张图都必须在视觉内容正下方有其图注
- 来源行应使用较小字体、斜体，放在图表最底部

## 使用本模板的说明

1. **第 1 页至关重要：** 第 1 页的执行摘要必须包含所有关键信息 - 快速事实、财务快照、3 张图表、估值摘要、论点和风险。这是最重要的一页。

2. **最大密度：** 专业股票研究的信息密度极高。每一页都应充满交错排列的文本、图表和表格。目标是 60-80% 页面覆盖率，并尽量减少留白。

3. **无孤立章节：** 绝不要让章节标题单独出现，或让单张图表/表格独占一页。始终组合元素。示例：不要把“财务快照”单独放在第 6 页 - 将其与周围内容整合。

4. **20-30+ 张图表：** 全文包含大量图形，特别强调：
   - **按产品/分部划分的收入**（堆叠面积图）
   - **按地理区域划分的收入**（堆叠柱状图）
   - **财务表现趋势**（多张图表）
   - 图表应嵌入文本中，而不是单独分组

5. **使用 DOC 技能：** 该大纲应使用 DOC 技能转换为专业 Word 文档，具有适当格式、样式、页眉/页脚和页码

6. **交错内容：** 文本段落应嵌入图表。每一页应有 2-4 个不同元素（表格、图表、文本块）。

7. **一致格式：** 全文对标题、正文、表格和图表使用一致样式。选择一种配色方案并坚持使用。

8. **引用：** 为所有数据点包含引用和来源

9. **校对：** 始终校对准确性，尤其是财务数据和计算

10. **最后写执行摘要：** 虽然它出现在第 1 页，但在完成完整分析后最后撰写本节

11. **平衡：** 客观呈现正面和负面方面

12. **具体 > 泛泛：** 使用具体数据和示例，而不是泛泛陈述
