# 启动报告的质量控制清单

在提交启动报告之前，请验证以下所有项目是否完整。

## 关键最低标准 - 报告必须满足这些要求

**如果出现以下情况，请勿交付：**
- ❌ DOCX 报告少于 30 页 → 不完整
- ❌ 嵌入图表少于 25 个 → 不完整
- ❌ 综合表少于 12 个 → 不完整
- ❌ 少于 10,000 字 → 不完整
- ❌ 无 XLS 财务模型 → 缺少交付
- ❌ 图表是文字描述，不是实际的 PNG/JPG 文件 → 重大失败

## 可交付成果清单

- [ ] DOCX 报告文件已创建
- [ ] XLS 财务模型文件已创建
- [ ] 两个文件均正确命名：`[Company]_Initiation_Report_[Date].docx` 和 `[Company]_Financial_Model_[Date].xlsx`

## DOCX 报告 - 长度和内容

**长度验证：**
- [ ] 报告为 30-50 页（计算最终文件的页数）
- [ ] Word 计数为 10,000-15,000 个字
- [ ] 如果少于 30 页：停止并添加更多内容

**视觉元素：**
- [ ] 嵌入 25-35 个图表（数：_____ 个图表）
- [ ] 所有图表都是实际的 PNG/JPG 图像文件（不是文字描述）
- [ ] 包括 12-20 个综合表格（数：_____ 个表格）
- [ ] 图表和表格散布在整个过程中，没有在最后分组

**图表要求：**
- [ ] 按产品划分的收入图表：堆叠区域格式 ✓
- [ ] 按地理位置划分的收入图表：堆积条形图格式 ✓
- [ ] DCF 灵敏度：带颜色编码的 2 路热图 ✓
- [ ] 估值足球场：水平条形图 ✓
- [ ] 所有其他图表均为实际图像文件 ✓

**表格要求：**
- [ ] 完整损益表（40-50 行），包含 5 年历史数据 + 5 年预测数据
- [ ] 完整现金流量表（30-40 行）
- [ ] 完整资产负债表（35-45 行）
- [ ] 按产品划分的收入表（20-30 行）
- [ ] 按地理位置划分的收入表（15-20 行）
- [ ] 按渠道划分的收入表（10-15 行）
- [ ] 可比公司表及统计摘要（最大/75th/中值/25th/min）
- [ ] DCF计算表（30-40行）
- [ ] WACC计算表（8-10行）
- [ ] 两个灵敏度表
- [ ] 2-3 个额外的财务/竞争表

## DOCX 报告 - 结构

**第 1 页要求：**
- [ ] 存在“INITIATING COVERAGE”标题（不是“公司更新”）
- [ ] 以论文为中心的标题（不是像“强劲的第四季度结果”这样的事件驱动的标题）
- [ ] 评级框，包含评级、价格、目标价格、52 周范围、市值、EV
- [ ] 3-4 个段落长度的项目符号，带有 ■ 字符和粗体标题
- [ ] 财务和估值指标表，包含 2-3 年历史数据和 2 年预测数据
- [ ] 表中“A”后缀表示实际值，“E”后缀表示估计值
- [ ] 所有视觉效果上的源行

**内容部分：**
- [ ] 目录（第 2 页）
- [ ] 投资论文与风险（3-5页）
- [ ] 公司概况（6-12页）包括：
  - [ ] 公司简介
  - [ ] 历史和里程碑
  - [ ] 管理简介（3-4 名高管各 300-400 字）
  - [ ] 产品/服务详情
  - [ ] 竞争格局
- [ ] 财务分析与预测（10-15 页）
- [ ] 估值分析（8-12页）
- [ ] 假设部分（2,000-3,000 字记录所有预测假设）
- [ ] 情景分析（1,500-2,000 个单词，包含牛/底/熊参数）
- [ ] 附录包括数据源和参考文献页面

## DOCX 报告 - 格式

**图表格式：**
- [ ] 每个图上面都有标题：“图 X - [Company] [描述性标题]”
- [ ] 每个图都有下面的源行：“来源：[带日期的具体来源]”
- [ ] 连续的图编号（图1、2、3...无间隙）
- [ ] 每个表格都有带有阴影的标题行
- [ ] 每个表的底部都有源代码行
- [ ] 所有年份均使用“A”表示实际值，“E”表示估计值

**专业格式化：**
- [ ] 字体始终一致（Calibri、Arial 或类似字体）
- [ ] 带页码的页眉和页脚
- [ ] 密集布局：60-80% 页面覆盖率，最小化空白
- [ ] 每个页面都有文本和视觉效果（图表或表格）
- [ ] 使用专业的业务报告模板

## 引文和来源 ⭐⭐⭐ 重要

**来源归属：**
- [ ] 每个数字都有特定的来源，包括文档名称和日期
- [ ] 每个表格都有具体来源和文档参考
- [ ] 整个文本中的关键统计数据都有脚注和来源
- [ ] 不仅仅是通用的“公司数据”——必须具体

**超链接：** ⭐⭐⭐ 强制
- [ ] 所有 URL 都是可点击的超链接（不是纯文本）
- [ ] SEC 文件超链接至 EDGAR 查看器
- [ ] 收益记录超链接（Seeking Alpha 或公司 IR）
- [ ] 新闻稿超链接至公司 IR 页面
- [ ] 超链接到 PDF URL 的演示文稿
- [ ] 行业报告超链接（如果公开）
- [ ] 订阅数据（Bloomberg、FactSet）注明“（需要订阅）”
- [ ] 任何地方都没有显示原始 URL - 全部格式化为超链接
- [ ] 测试 3-5 个示例超链接以确保它们有效（Ctrl+单击）

**参考页：**
- [ ] 报告末尾的“数据源和参考”页面
- [ ] 列出报告中使用的所有来源
- [ ] 按类别组织的来源（SEC 文件、收益记录等）
- [ ] 每个来源都有日期
- [ ] 每个来源都有可点击的超链接（如果适用）

## XLS 金融模型 - 结构

**文件结构：**
- [ ] Excel 工作簿中超过 15 个选项卡
- [ ] 选项卡包括：执行摘要、假设、历史财务、收入模型、运营费用、损益表、资产负债表、现金流、支持时间表、DCF 估值、比较分析、先例交易、情景、敏感性分析、图表

**格式：**
- [ ] 蓝色文本表示硬编码输入
- [ ] 公式的黑色文本
- [ ] 绿色文本用于链接到其他工作表
- [ ] 带边框和底纹的专业格式
- [ ] 清除节标题和标签

**模型功能：**
- [ ] 所有数字流动（改变假设→整个模型更新）
- [ ] DCF 链接到假设和预测
- [ ] 没有循环引用或错误
- [ ] 所有重要的单元格/范围均已命名
- [ ] 灵敏度表动态工作

## XLS 金融模型 - 内容

**预测：**
- [ ] 3-5年历史数据
- [ ] 5 年远期预测（FY+1 至 FY+5）
- [ ] 按产品、地理位置、渠道细分的收入
- [ ] 包含 40-50 个行项目的完整损益表
- [ ] 30-40 个项目的完整现金流
- [ ] 包含 35-45 个项目的完整资产负债表

**估值：**
- [ ] 完整的 DCF 模型，显示所有计算结果
- [ ] WACC 所有组件的计算
- [ ] 终值计算
- [ ] 可比公司分析（5-10家公司）
- [ ] 先例交易分析（5-10 笔交易）
- [ ] 情景分析（牛市/基本市/熊市）
- [ ] 两个灵敏度表

## 跨文件一致性

**关键**：DOCX 和 XLS 之间的数字必须完全匹配

- [ ] 两个文件中的收入数字均匹配
- [ ] EPS 数字在两个文件中匹配
- [ ] 两个文件的保证金百分比匹配
- [ ] 两个文件中的评估数字均匹配
- [ ] 两个文件的价格目标均匹配
- [ ] 两个文件中的所有预计年份均匹配

**验证方法**：抽查DOCX报告和XLS模型之间的10-15个关键数字。

## 内容质量

**投资论文：**
- [ ] 3-5个明确的论文支柱
- [ ] 每个支柱都有具体的数据和量化支持
- [ ] 量化每个支柱的财务影响
- [ ] 确定时间表的催化剂

**分析深度：**
- [ ] 综合商业模式分析
- [ ] 详细的竞争评估
- [ ] 3-5年财务趋势分析
- [ ] 8-12 风险识别和量化
- [ ] 管理团队分析（每位高管 300-400 字）

**假设：**
- [ ] 2,000-3,000 字记录所有假设
- [ ] 按类别/地区划分的收入增长假设
- [ ] 桥梁显示司机的利润假设
- [ ] 营运资金假设
- [ ] CapEx 假设
- [ ] 每个假设都有具体的量化

**场景：**
- [ ] 情景分析 1,500-2,000 字
- [ ] 具有特定参数和催化剂的牛市情况
- [ ] 带有详细理由的基本案例
- [ ] 具有特定触发因素的熊市案例
- [ ] 每个场景的概率评估

## 写作质量

**款式：**
- [ ] 以数字为线索（“收入增长 15%，达到 $1.2B”，而不是“强劲收入”）
- [ ] 使用“对比”不是“对抗”
- [ ] 直接、简洁
- [ ] 贯穿始终的专业机构基调
- [ ] 没有非正式语言

**准确度：**
- [ ] 股票代码中没有拼写错误
- [ ] 公司名称无拼写错误
- [ ] 所有日期均准确
- [ ] 所有计算均已验证
- [ ] 图表与文字描述相符
- [ ] 所有数字格式正确（$ 符号、% 符号、逗号）

## 交货前最终检查

快速完成最终审查：

1. **可交付成果**：创建了 DOCX 和 XLS 文件 ✓
2. **长度**：DOCX 为 30-50 页 ✓
3. **图表**：嵌入 25-35 个实际 PNG/JPG 文件 ✓
4. **表格**：包括 12-20 个综合表格 ✓
5. **字数**：10,000-15,000 字 ✓
6. **超链接**：测试 3-5 个超链接 - 全部有效 ✓
7. **交叉检查**：抽查 DOCX 和 XLS 之间的 10 个号码是否匹配 ✓
8. **第 1 页**：存在“INITIATING COVERAGE”标题 ✓

如果任何物品失败，请勿交付。返回并修复。
