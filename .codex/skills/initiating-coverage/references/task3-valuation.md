### 第 2 步：构建 DCF 分析

#### A. 计算 WACC

**1. 确定无风险利率**
   - 使用 10 年期美国国债收益率（检查当前利率）
   - 示例：截至 2024 年末为 4.0-4.5%

**2. 确定股权成本（CAPM）**
   ```
   股权成本 = 无风险利率 + Beta × 股权风险溢价

   输入：
   - 无风险利率：[当前 10 年期美国国债，例如 4.2%]
   - Beta：[来自 Bloomberg/FactSet 的公司 beta 或同行平均值]
   - 股权风险溢价：5-6%（历史平均）

   示例：
   股权成本 = 4.2% + 1.3 × 5.5% = 11.35%
   ```

**3. 确定债务成本**
   ```
   债务成本 = 当前借款利率或债券隐含收益率

   对于私营公司：
   债务成本 = 无风险利率 + 信用利差（基于评级）

   示例：
   债务成本（税前）= 6.5%
   债务成本（税后）= 6.5% × (1 - 25% 税率) = 4.875%
   ```

**4. 确定资本结构**
   ```
   使用市场价值（不是账面价值）：

   股权市场价值 (E) = 股价 × 流通股数
   债务市场价值 (D) = 总债务（如果债券不交易，则使用账面价值）
   总价值 (V) = E + D

   股权权重 = E / V
   债务权重 = D / V

   示例：
   E = $5,000M (90.9%)
   D = $500M (9.1%)
   V = $5,500M (100%)
   ```

**5. 计算 WACC**
   ```
   WACC = (E/V × 股权成本) + (D/V × 债务成本 × (1 - 税率))

   示例：
   WACC = (90.9% × 11.35%) + (9.1% × 6.5% × (1 - 25%))
   WACC = 10.32% + 0.44% = 10.76%

   四舍五入为：基准情景 10.8%
   ```

#### B. 计算终值

**方法 1：永续增长（首选）**
```
终值 = FCF(2029) × (1 + g) / (WACC - g)

其中：
- FCF(2029) = 模型中的最后一年无杠杆 FCF
- g = 永续增长率（通常 2.0-3.0%）
  - 不应超过长期 GDP 增长
  - 基准情景使用 2.5%

示例：
FCF(2029) = $500M
g = 2.5%
WACC = 10.8%

终值 = $500M × (1.025) / (0.108 - 0.025)
终值 = $512.5M / 0.083 = $6,175M
```

**方法 2：退出倍数（备选）**
```
终值 = EBITDA(2029) × 退出倍数

其中：
- 退出倍数 = 当前同行交易中位数（例如 12-15x EBITDA）

示例：
EBITDA(2029) = $800M
退出倍数 = 13x

终值 = $800M × 13x = $10,400M
```

**选择一种方法或对两者取平均。**

#### C. 将现金流折现至现值

```
预测 FCF 的 PV = Σ [FCFt / (1 + WACC)^t]，t = 1 到 5

示例：
年份    FCF      折现       FCF 的 PV
        ($M)     因子       ($M)
2025    $250     1/(1.108)^1 = 0.9026    $226
2026    $320     1/(1.108)^2 = 0.8147    $261
2027    $390     1/(1.108)^3 = 0.7353    $287
2028    $450     1/(1.108)^4 = 0.6636    $299
2029    $500     1/(1.108)^5 = 0.5988    $299
                              总 PV:    $1,372M

终值的 PV = 终值 / (1 + WACC)^5
终值的 PV = $6,175M / (1.108)^5 = $6,175M × 0.5988 = $3,697M

企业价值 = $1,372M + $3,697M = $5,069M
```

#### D. 计算股权价值和每股价格

```
企业价值                         $5,069M
- 净债务（债务 - 现金）          ($450M)
+ 非经营性资产                   $0M
- 少数股东权益                   $0M
- 优先股                         $0M
= 股权价值                       $4,619M

稀释后流通股数                   100M

每股价格 = $4,619M / 100M = $46.19

当前股价：$42.00
隐含上涨空间：10.0%
```

### 第 3 步：可比公司分析

#### A. 选择可比公司

**选择标准：**
- 同一行业/板块（主要要求）
- 相似商业模式
- 可比规模（市值、收入）
- 相似增长特征
- 相似地域

**识别 5-10 家同行公司：**
1. [Peer 1] - 直接竞争对手
2. [Peer 2] - 直接竞争对手
3. [Peer 3] - 相邻参与者
4. [Peer 4] - 相似商业模式
5. [Peer 5] - 区域竞争对手
6. [Add 3-5 more]

**记录选择每个同行的理由。**

#### B. 收集同行财务数据

**对每个可比公司，收集：**
- 当前股价
- 流通股数（稀释后）
- 市值
- 总债务和现金（用于 EV 计算）
- 企业价值
- LTM（最近十二个月）财务数据：
  - 收入
  - EBITDA
  - EBIT
  - 净利润
- NTM（未来十二个月）一致预期
- 收入增长率
- EBITDA 利润率

**数据来源：**
- FactSet、CapitalIQ、Bloomberg（首选）
- 公司 10-K/10-Q 文件用于实际数据
- 来自 Yahoo Finance、Seeking Alpha 的一致预期（如果专业工具不可用）

#### C. 计算估值倍数

**对每个同行，计算：**
```
EV/Revenue (LTM) = 企业价值 / LTM 收入
EV/Revenue (NTM) = 企业价值 / NTM 收入（估计）
EV/EBITDA (LTM) = 企业价值 / LTM EBITDA
EV/EBITDA (NTM) = 企业价值 / NTM EBITDA（估计）
P/E (NTM) = 市值 / NTM 净利润（估计）
```

#### E. 将倍数应用于目标公司

**选择主要倍数（成熟公司通常使用 EV/EBITDA）：**

```
目标公司 NTM EBITDA = $550M（来自财务模型）

应用同行中位数倍数：
同行中位 EV/EBITDA (NTM) = 13.8x
隐含 EV = $550M × 13.8x = $7,590M

应用第 25 百分位（保守）：
第 25 百分位 EV/EBITDA (NTM) = 12.5x
隐含 EV = $550M × 12.5x = $6,875M

应用第 75 百分位（乐观）：
第 75 百分位 EV/EBITDA (NTM) = 14.1x
隐含 EV = $550M × 14.1x = $7,755M

估值区间（Comps）：$6,875M - $7,755M
中点：$7,315M

转换为股权价值：
隐含 EV（中位数）        $7,590M
- 净债务                 ($450M)
= 隐含股权价值           $7,140M

流通股数                 100M
隐含每股价格             $71.40
```

**说明溢价/折价理由：**
- 目标公司增长 17% vs. 同行中位数 17% → 一致
- 目标公司 EBITDA 利润率 23% vs. 同行中位数 23% → 一致
- 目标公司市场地位 → [Justify premium/discount]
- **结论**：应用中位数倍数（不调整）

#### B. 确定权重理由

**典型权重：**
- DCF：40-60%（预测可靠时更高）
- 交易可比公司：25-40%（反映市场情绪）
- 先例交易：10-25%（除非 M&A 可能性高，否则较低）

**对于此示例：**
- DCF 50%：对预测的置信度高
- Comps 40%：同行组稳健
- Precedent 10%：近期不太可能发生 M&A

## 合理性检查

**始终执行这些验证检查：**

1. **历史倍数检查**
   - 隐含倍数是否与公司的历史交易区间一致？
   - 如果不一致，解释原因

2. **同行比较**
   - 相对于同行的溢价/折价是否由基本面支持？
   - 检查：增长、利润率、市场地位

3. **隐含增长检查**
   - 当前价格中市场计入了什么增长？
   - 鉴于公司轨迹，这是否合理？

4. **市值合理性**
   - 鉴于公司规模和同行，总市值是否合理？
   - 相对于行业，公司是否会过大/过小？

5. **终值检查**
   - 终值是否 < 总企业价值的 60-70%？
   - 如果 > 70%，预测期可能不够长

6. **WACC 合理性**
   - 对典型公司而言，WACC 是否在 8-14% 区间？
   - 科技/高增长：10-14%
   - 成熟/稳定：7-10%

7. **隐含回报检查**
   - 从当前价格到 12 个月目标价的 IRR 是多少？
   - 这是否与评级建议一致？
