## 贴现现金流 (DCF) 分析

### 概述

DCF 分析基于公司预计未来现金流的现值对公司进行估值。这被认为是理论上最稳健的估值方法，因为它基于基本价值创造。

### DCF 分步流程

#### 1. 历史财务分析
- 收集 3-5 年的历史财务数据
- 计算历史 FCF = EBIT(1-税率) + D&A - CapEx - NWC 变化
- 分析历史增长率和利润率
- 识别趋势和周期性

#### 2. 建立收入预测（5-10 年）
**方法：**
- **自上而下**：从市场规模 (TAM) 开始 → 市场份额 → 收入
- **自下而上**：售出单位 × 每单位价格
- **混合**：结合多个驱动因素

**关键考虑因素：**
- 管理层指引和历史增长
- 行业增长率和市场趋势
- 竞争动态和市场份额演变
- 产品管线和新市场机会
- 宏观经济因素

#### 3. 预测营业费用
- **COGS**：按收入百分比（分析历史利润率）
- **SG&A**：通常半固定；按收入百分比建模并考虑规模效应
- **R&D**：对科技/制药至关重要；按收入百分比建模
- **D&A**：基于 CapEx 假设

**计算 EBIT** = 收入 - COGS - 营业费用

#### 4. 计算无杠杆自由现金流
```
EBIT
× (1 - Tax Rate)
= NOPAT (Net Operating Profit After Tax)
+ Depreciation & Amortization
- Capital Expenditures
- Increase in Net Working Capital
= Unlevered Free Cash Flow (UFCF)
```

**CapEx 假设：**
- 维护性 CapEx：维持当前运营所需（通常为收入的 2-4%）
- 增长性 CapEx：扩张所需
- 考虑行业基准和公司指引

**净营运资金：**
- NWC =（应收账款 + 存货）- 应付账款
- 按收入百分比或天数（DSO、DIO、DPO）建模
- NWC 增加是现金的使用

#### 5. 确定终值

**方法 A：永续增长法**
```
Terminal Value = FCF(final year) × (1 + g) / (WACC - g)
```
- g = 永续增长率（通常为 2-3%，不超过 GDP 增长率）
- 当公司已达到稳定、成熟增长时使用

**方法 B：退出倍数法**
```
Terminal Value = EBITDA(final year) × Exit Multiple
```
- 退出倍数基于当前交易可比公司
- 更适用于周期性企业

#### 6. 计算加权平均资本成本 (WACC)

```
WACC = (E/V × Cost of Equity) + (D/V × Cost of Debt × (1 - Tax Rate))
```

**股权成本（使用 CAPM）：**
```
Cost of Equity = Risk-Free Rate + Beta × Equity Risk Premium
```
- 无风险利率：10 年期国债收益率
- Beta：股票收益与市场的回归（或使用可比 beta）
- 股权风险溢价：历史平均约 5-6%

**债务成本：**
```
Cost of Debt = Risk-Free Rate + Credit Spread
```
- 使用公司当前借款利率或债券隐含利率
- 如果没有未偿债券，则根据信用评级调整

**资本结构：**
- E/V = 股权市场价值 / 总价值
- D/V = 债务市场价值 / 总价值
- 使用目标资本结构，而不是当前资本结构（如果显著不同）

#### 7. 将现金流折现至现值

```
PV = Σ [FCFt / (1 + WACC)^t] + [Terminal Value / (1 + WACC)^n]
```

#### 8. 计算企业价值和股权价值

```
Enterprise Value = PV of Projected FCF + PV of Terminal Value
Less: Net Debt (Total Debt - Cash)
Plus: Non-operating Assets
Less: Minority Interest
Less: Preferred Stock
= Equity Value

Price Per Share = Equity Value / Diluted Shares Outstanding
```

### DCF 敏感性分析

始终对关键变量进行敏感性分析：

1. **双向敏感性表**：WACC vs. 终值增长率
2. **收入增长情景**：基础 / 牛市 / 熊市案例
3. **利润率假设**：经营杠杆情景
4. **终值倍数敏感性**：如果使用退出倍数法

**敏感性表示例：**
```
           Terminal Growth Rate
WACC      2.0%    2.5%    3.0%
8.0%      $45     $48     $52
9.0%      $40     $43     $46
10.0%     $36     $39     $41
```

### 需要避免的常见 DCF 陷阱

1. **重复计算增长**：不要在没有相应投资（CapEx、NWC）的情况下预测高增长
2. **不现实的终值增长**：不应超过长期 GDP 增长
3. **忽视周期性**：对周期性企业的盈利进行正常化
4. **错误的现金流定义**：使用无杠杆 FCF，而不是净利润
5. **假设不一致**：使贴现率与现金流匹配（无杠杆 FCF → WACC）

## 交易可比公司分析

### 概述

交易可比公司法基于相似公司在公开市场上的估值来对公司进行估值。这反映当前市场情绪和相对估值。

### 可比公司分步流程

#### 1. 选择可比公司

**选择标准：**
- 相同的行业/板块（主要标准）
- 相似的商业模式和收入来源
- 可比规模（市值、收入）
- 相似的增长特征和利润率
- 相似的终端市场和地区

**典型范围：**
- 从 8-15 家公司开始
- 剔除具有特殊情况的公司
- 最终形成 5-10 家公司的集合

#### 2. 收集财务信息

**所需数据：**
- 当前股价和已发行股票
- 最新财政年度财务报表
- 来年 (NTM) 的一致预期
- 历史增长率

**计算市场指标：**
- 市值 = 股价 × 已发行股票
- 企业价值 = 市值 + 债务 + 少数股东权益 + 优先股 - 现金
- 净债务 = 总债务 - 现金及等价物

#### 3. 计算估值倍数

**企业价值倍数：**
- **EV/Revenue**：适用于早期/高增长公司
- **EV/EBITDA**：最常见；适用于资本密集型企业
- **EV/EBIT**：当 D&A 差异显著时有用

**股权价值倍数：**
- **P/E (Price/Earnings)**：使用最广泛
- **P/B (Price/Book)**：适用于金融机构
- **P/S (Price/Sales)**：适用于未盈利公司

**计算对象：**
- 最近十二个月 (LTM) - 历史
- 未来十二个月 (NTM) - 前瞻性（首选）

#### 4. 分析并选择倍数

**创建可比公司表：**

| 公司 | 市值 | EV/Revenue | EV/EBITDA | EV/EBIT | P/E (NTM) | 收入增长 | EBITDA 利润率 |
|---------|-----------|------------|-----------|---------|-----------|----------------|---------------|
| Comp A  | $10B      | 3.5x       | 12.0x     | 18.0x   | 22.0x     | 15%            | 28%           |
| Comp B  | $8B       | 3.0x       | 10.5x     | 16.0x   | 19.0x     | 12%            | 27%           |
| ...     | ...       | ...        | ...       | ...     | ...       | ...            | ...           |
| 中位数  | -         | **3.2x**   | **11.0x** | **17.0x** | **20.5x** | 13%            | 27.5%         |

**调整：**
- 剔除异常值（通常 >2 个标准差）
- 考虑使用中位数而非平均值（受异常值影响较小）
- 如果某些可比公司更具可比性，则对倍数加权
- 根据增长、利润率、风险差异进行调整

#### 5. 将倍数应用于目标公司

**计算示例：**
```
Target Company NTM EBITDA = $500M
Selected EV/EBITDA Multiple = 11.0x
Implied Enterprise Value = $500M × 11.0x = $5,500M

Less: Net Debt = $1,000M
Equity Value = $4,500M

Shares Outstanding = 100M
Implied Price Per Share = $45.00
```

#### 6. 选择适当的倍数

**基于以下因素选择：**
- **EV/Revenue**：高增长、未盈利公司（科技、生物技术盈利前阶段）
- **EV/EBITDA**：最常见；资本密集型行业（制造、电信）
- **P/E**：资本结构稳定的盈利公司（消费、零售）
- **行业特定**：银行使用 P/B，石油和天然气使用 EV/Production，媒体使用 EV/Subscriber

### 溢价/折价分析

基于以下因素应用溢价或折价：
- **增长溢价**：更高增长 → 更高倍数
- **盈利能力**：更高利润率 → 更高倍数
- **规模**：较大公司通常以溢价交易（流动性）
- **市场地位**：市场领导者 → 溢价
- **地理**：发达市场 vs. 新兴市场

## 先例交易分析

### 概述

先例交易法基于并购交易中为相似公司支付的价格来对公司进行估值。这反映控制权溢价和战略价值。

### 分步流程

#### 1. 识别相关交易

**选择标准：**
- 相同或相似行业
- 相似规模（在目标公司规模的 0.5x 至 2x 以内）
- 相似的业务特征
- 近期交易（优先使用过去 3-5 年）
- 已宣布并完成的交易（避免撤回交易）

**典型范围：**
- 至少 5-10 笔交易
- 关注近期交易（对越近期的交易给予越高权重）

#### 2. 收集交易详情

**所需信息：**
- 交易日期（公告和交割）
- 收购价格和结构（现金、股票、混合）
- 交易时目标公司的财务数据
- 战略理由和协同效应
- 支付的控制权溢价

**来源：**
- SEC 文件（S-4、8-K、委托书）
- 新闻稿和投资者演示
- M&A 数据库（CapIQ、FactSet、Bloomberg）

#### 3. 计算交易倍数

**与交易可比公司相同的倍数，但基于交易价值：**

```
Transaction Value = Equity Purchase Price + Assumed Debt - Cash Acquired

EV/Revenue (LTM) = Transaction Value / Target's LTM Revenue
EV/EBITDA (LTM) = Transaction Value / Target's LTM EBITDA
EV/EBIT (LTM) = Transaction Value / Target's LTM EBIT
```

**计算控制权溢价：**
```
Control Premium = (Offer Price - Unaffected Price) / Unaffected Price
```
- 未受影响价格 = 目标公司公告前 1-2 天的股价
- 典型范围：20-40%

#### 4. 分析先例交易

**创建先例交易表：**

| 日期 | 目标公司 | 收购方 | 交易价值 | EV/Revenue | EV/EBITDA | 溢价 | 理由 |
|------|--------|----------|------------|------------|-----------|---------|-----------|
| Q1'24 | CompX | BuyerA | $5.0B | 4.0x | 14.0x | 35% | 市场整合 |
| Q3'23 | CompY | BuyerB | $3.5B | 3.5x | 12.5x | 28% | 战略契合 |
| 中位数 | - | - | - | **3.8x** | **13.0x** | **31%** | - |

#### 5. 应用于目标公司

**重要考虑因素：**
- 先例交易倍数通常高于交易可比公司（包含控制权溢价）
- 根据交易理由差异进行调整
- 考虑交易时的市场状况与当前市场状况
- 对近期交易给予更高权重

**计算示例：**
```
Target Company LTM EBITDA = $450M
Selected EV/EBITDA Multiple = 13.0x (precedent)
vs Trading Comps Multiple = 11.0x

Implied EV (Precedent) = $450M × 13.0x = $5,850M
Implied EV (Trading) = $450M × 11.0x = $4,950M

Implied Control Premium = $5,850M / $4,950M - 1 = 18%
```

### 对交易倍数的调整

**考虑针对以下因素调整：**
- **市场状况**：牛市 vs. 熊市（M&A 活动水平）
- **交易结构**：战略买方 vs. 财务买方
- **协同效应**：具有高协同效应的交易会获得溢价
- **竞争动态**：单一竞标方 vs. 多个竞标方
- **时间价值**：较旧的交易相关性较低

## 估值调和

### 创建估值桥

在单一框架中呈现全部三种方法：

**估值摘要示例：**

| 方法 | 企业价值 | 股权价值 | 每股价格 | 权重 | 隐含价值 |
|--------|------------------|--------------|-------------|--------|---------------|
| DCF 分析 | $5,200M | $4,200M | $42.00 | 50% | $21.00 |
| 交易可比公司 | $5,500M | $4,500M | $45.00 | 30% | $13.50 |
| 先例交易 | $5,850M | $4,850M | $48.50 | 20% | $9.70 |
| **加权平均** | - | - | **$44.20** | - | **$44.20** |

### 对方法进行加权

**典型权重：**
- **DCF**：40-60%（基本价值，但假设预测准确）
- **交易可比公司**：25-40%（反映当前市场情绪）
- **先例交易**：15-25%（除非 M&A 可能发生，否则相关性较低）

**基于以下因素调整权重：**
- **对预测的信心**：信心越高 → DCF 权重越高
- **市场状况**：牛市/熊市影响可比公司可靠性
- **M&A 可能性**：如果公司可能被收购或行业正在整合，则更高
- **公司成熟度**：成熟公司 → 对可比公司赋予更高权重；成长型 → DCF 权重更高

### 估值范围

始终呈现估值范围，而不是单点估计：

**方法：**
- **基础案例**：最可能的情景
- **牛市案例**：乐观假设（收入增长、利润率）
- **熊市案例**：保守假设

**示例：**
```
Bear Case: $38 - $40
Base Case: $42 - $46
Bull Case: $48 - $52

Recommendation: BUY with target price of $45 (midpoint of base case)
```

### 合理性检查

**用以下方面交叉检查估值：**
1. **历史倍数**：当前估值是否与历史一致？
2. **同业比较**：相对于同业的溢价/折价是否合理？
3. **隐含增长**：市场正在定价什么增长？
4. **隐含回报**：从当前价格到目标价格的 IRR
5. **市值分析**：总市值是否合理？

---

## 结论

使用全部三种估值方法为确定公允价值提供了稳健框架：

- **DCF** 提供基于基本面的内在价值
- **交易可比公司** 反映当前市场估值
- **先例交易** 表明 M&A 价值和控制权溢价

关键是理解驱动每种方法的假设，并呈现一个考虑多种情景和方法的、理由充分的估值范围。
