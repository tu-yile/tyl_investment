# 想法生成

description: 系统化股票筛选和投资想法来源挖掘。结合量化筛选、主题研究和模式识别，发现新的做多和做空想法。用于寻找新想法、运行筛选或开展主题扫描。触发词包括“想法生成”、“股票筛选”、“寻找想法”、“有什么值得关注”、“筛选”、“新想法”或“给我推荐一个想法”。

## 工作流程

### 步骤 1：定义搜索条件

向用户询问参数：
- **方向**：做多想法、做空想法，或两者都有
- **市值**：大盘、中盘、小盘、微盘
- **行业**：特定行业或跨行业
- **风格**：价值、成长、质量、特殊情形、事件驱动
- **地域**：美国、国际、全球
- **主题**：任何具体主题角度（AI、回流制造、人口老龄化等）

### 步骤 2：量化筛选

根据风格运行筛选：

**价值筛选**
- P/E 低于行业中位数
- EV/EBITDA 低于历史平均
- 自由现金流收益率 >5%
- 市净率低于 1.5x
- 过去 90 天内部人买入
- 股息收益率高于市场平均

**成长筛选**
- 收入同比增长 >15%
- 盈利同比增长 >20%
- 收入加速（增长率提高）
- 利润率扩张
- 高投入资本回报率（>15%）
- 强劲净留存率（SaaS >110%）

**质量筛选**
- 持续收入增长（5 年以上）
- 稳定或扩张的利润率
- ROE >15%
- 低债务/权益比
- 高自由现金流转化率
- 内部人持股 >5%

**做空筛选**
- 收入下滑或增长放缓
- 利润率压缩
- 应收账款 / 存货相对于销售上升
- 内部人卖出
- 相对同业存在无合理依据的估值溢价
- 基本面恶化且空头仓位高
- 会计危险信号（审计师变更、重述）

**特殊情形筛选**
- 近期 IPO / SPAC 且锁定期到期
- 过去 12 个月内分拆上市
- 正从重组中走出的公司
- 激进投资者介入
- 表现不佳公司的管理层变动

### 步骤 3：主题扫描

对于主题想法，研究主题并识别受益者：

1. 定义投资逻辑（例如，“AI 基础设施支出加速至 2026 年”）
2. 绘制价值链——谁直接受益 vs. 间接受益？
3. 识别纯标的 vs. 多元化敞口
4. 评估哪些名称已经“被计入价格” vs. 被低估
5. 寻找市场尚未把它们与主题联系起来的二阶受益者

### 步骤 4：想法呈现

对于每个通过筛选的想法，呈现：

**[公司名称]——[做多/做空]——[一句话投资逻辑]**

| 指标 | 数值 | vs. 同业 |
|--------|-------|-----------|
| 市值 | | |
| EV/EBITDA（NTM） | | |
| P/E（NTM） | | |
| 收入增长 | | |
| EBITDA 利润率 | | |
| FCF 收益率 | | |

**投资逻辑（3-5 条）：**
- 为什么它被错误定价
- 市场漏看了什么
- 实现价值的催化剂

**关键风险：**
- 什么会使这个判断错误

**建议的下一步：**
- 建完整模型？深度尽调？专家访谈？

### 步骤 5：输出

- 包含一页总结的 5-10 个想法候选名单
- 记录筛选条件和方法论
- 所有想法的比较表
- 优先级列表：哪些想法应先研究

## 重要说明

- 筛选发现的是候选项，不是结论——每个筛选输出都需要基本面工作
- 最好的想法往往来自交叉点（例如，因暂时逆风而以价值价格交易的质量公司）
- 避免拥挤交易——检查持有人数据、空头仓位，以及覆盖该名称的分析师数量
- 逆向想法需要催化剂——没有催化剂的早到，等同于错误
- 随时间跟踪想法命中率——哪些筛选和方法产生最好的想法？
- 做空想法需要更高确信度——时点更难，风险不对称
